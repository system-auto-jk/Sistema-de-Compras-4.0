✨ Recursos Principais

Gerenciar Listas

Crie, edite e organize múltiplas listas de compras com facilidade. Personalize cada uma conforme sua necessidade.

Adicionar Itens

Adicione itens com marca e quantidade. Sistema de sugestões aprende seus itens favoritos automaticamente.

Exporte para PDF, JSON ou WhatsApp. Compartilhe suas listas com amigos e família facilmente.

📖 Como Usar

1

Crie uma Lista

Vá para Gerenciar → Digite o nome da sua lista → Clique em + para criar. Perfeito para organizar compras por categoria (supermercado, farmácia, etc).

2

Adicione Itens

Selecione a lista → Clique em Adicionar → Preencha nome, marca (opcional) e quantidade. O sistema memoriza seus itens frequentes!

3

Compre e Registre Preços

Na loja, clique no checkbox do item → Informe o preço pago → Confirme. O total é calculado automaticamente!

4

Finalize e Analise

Clique em Finalizar → Revise o resumo → Confirme. Veja histórico completo e estatísticas mensais de gastos.

❓ Perguntas Frequentes

Como os dados são salvos?

▼
Todos os seus dados são salvos localmente no seu dispositivo usando armazenamento seguro. Nada é enviado para servidores externos. Mesmo offline, você pode acessar suas listas!

Posso usar em múltiplos dispositivos?

▼
No momento, cada dispositivo tem seu próprio armazenamento. Mas você pode exportar suas listas como JSON em um dispositivo e importar em outro facilmente!

Como editar um item após adicionado?

▼
Clique no ícone de edição (lápis) ao lado do item. Você pode alterar nome, marca e quantidade. Se o item foi comprado, também pode ajustar o preço.

Posso compartilhar com outras pessoas?

▼
Sim! Você pode compartilhar via WhatsApp (com formatação), PDF ou enviar o arquivo JSON para outra pessoa importar. Excelente para compras em grupo!

Como limpar meus dados?

▼
Vá para Configurações → Limpar Dados. Cuidado: esta ação é irreversível e deletará todas as listas e histórico!

Funciona offline?

▼
Sim! É uma Progressive Web App (PWA). Uma vez carregado, funciona completamente offline. Apenas a exportação para WhatsApp necessita conexão.

Gerenciar Listas

O que é possível fazer:

  • Criar: Digite o nome e clique em + para criar uma nova lista
  • Duplicar: Crie cópias de listas existentes para reutilizar estruturas
  • Deletar: Remova listas que não precisa mais
  • Ver: Acesse suas listas a qualquer hora

Dicas Úteis:

Organização: Crie listas por categoria:
  • Supermercado
  • Farmácia
  • Padaria
  • Festa de fim de semana
Reutilização: Crie uma lista padrão e duplique quando for fazer novas compras!

Adicionar Itens

Campos para Preencher:

  • Nome: Nome do item (obrigatório)
  • Marca: Marca do produto (opcional, mas útil!)
  • Quantidade: Quantas unidades precisa (padrão: 1)

Sistema de Sugestões:

O sistema aprende seus itens frequentes! Conforme você adiciona itens, eles aparecem como sugestões ao digitar.

Onde Adicionar:

Local 1: Na seção "Gerenciar Listas", há um formulário de adição
Local 2: Ao visualizar uma lista, clique no botão + na barra inferior (mobile) ou use a seção lateral
Dica: Adicione a marca do produto para encontrar exatamente o que procura na loja!

Registrar Compras

Processo de Compra:

Passo 1: Clique no checkbox ao lado do item
Passo 2: Um modal aparecerá pedindo o preço
Passo 3: Informe o preço pago e a quantidade
Passo 4: Clique em Confirmar

O que Acontece:

  • ✅ Item é marcado como comprado
  • 💰 Total é calculado automaticamente (preço × quantidade)
  • 📊 Progresso visual é atualizado
  • 🔊 Som de confirmação (pode desativar em Configurações)

Editar Preço:

Clique no ícone de edição (lápis) do item para ajustar preço após comprado

Finalizar Compras

O que é Finalizar:

Finalizar é o processo de encerrar uma compra e registrá-la no histórico permanentemente.

Passos:

1: Compre seus itens e marque como comprado
2: Clique em "Finalizar" (botão na barra inferior ou seção de ações)
3: Revise o resumo (total e itens não comprados)
4: Clique em "Finalizar Compra"

O Que Acontece:

  • ✅ Compra é registrada no histórico com data e hora
  • 📊 Dados alimentam as estatísticas mensais
  • 📤 Pode exportar ou compartilhar resultado
  • 🔄 Lista permanece para próxima compra

Nota Importante:

Itens não comprados são mostrados para referência. Você ainda pode comprar depois!

Histórico & Estatísticas

O Histórico:

Mantém registro de todas as compras finalizadas com:

  • 📅 Data e hora da compra
  • 📋 Lista utilizada
  • 💰 Valor total gasto
  • 📝 Itens comprados (com preços)

Clicando em um Histórico:

Você pode compartilhar via WhatsApp com os detalhes completos da compra!

Estatísticas:

O que você vê:
  • Total gasto no mês atual
  • Média por compra
  • Listagem de todas as compras do mês

Dica:

Use as estatísticas para controlar seus gastos e identificar padrões de consumo!

Exportar & Compartilhar

Formatos de Exportação:

📄 JSON: Formato técnico para backup ou importar em outro dispositivo
📕 PDF: Arquivo imprimível com lista formatada para levar na bolsa ou imprimir
💬 WhatsApp: Compartilhe via WhatsApp com formatação automática

Como Usar:

  • Na seção "Gerenciar Listas", selecione uma lista
  • Clique em um dos botões de exportação
  • O arquivo será baixado ou a conversa do WhatsApp será aberta

WhatsApp:

A exportação inclui emojis e formatação para ficar bonito no chat! Perfeito para compartilhar com amigos ou companheiros de compra.

Importar de Volta:

Se você receber um arquivo JSON, em "Gerenciar Listas" clique em "Importar" e selecione o arquivo. A lista será adicionada ao seu sistema!
